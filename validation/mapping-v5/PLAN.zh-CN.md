# Agent 证据审查与新真实模型试验协议

[English](PLAN.md)

这是已批准的 1.9 之后的 2.0 工作，遵循维护者的次版本“逢十进一”规则。
mapping-v4 的旧文件和评分保持冻结。本协议在 Agent 实现变更前记录。

## 产品工作

1. 分阶段、直接和批量 Agent 建议及 Studio 预览共用结构化审查表示，包含准确的
   来源路径／哈希／类型化身份、筛选条件、种子与数量契约、来源单位、归约或推导、
   原文位置与上下文、原值和期望值、来源行／单元格／指针、诊断和理由。
   截断证据必须说明总量并保留进一步查看的路径。
2. 区分确定性验证事实和模型自述。数值相同不能证明实验身份；展示冲突和身份
   证据缺口，但不把正文数值过期等同于映射错误。可明确拒答并解释缺少什么。
   耗尽预算和无效动作不能计作正确拒答。
3. 给分阶段 Agent 简洁的当前阶段指导，在结束前展示来源单位与原文格式的比较。
   允许有界纠正，保留上一个有效草稿和原始输入身份。不加入特定任务答案、评分器
   反馈或无人确认的自动接受。
4. 实际写入继续要求新鲜建议、用户明确选择和确认。切换语言保留表单和选择，
   清除确认。检查 CLI、MCP 和真实双语 Studio，覆盖原生位置、过期输入和建议导入。

## 失败诊断和旧任务回归

依据机器可读契约和原始模型动作诊断，不依据模型声称“成功”。mapping-v4 第二轮
在七个可映射任务中提出正确原位置，但仍有五个来源单位错误、一个显示精度错误、
一个错误来源／JSON 指针契约；另外两个可映射任务耗尽错误预算。三个必须拒答的
任务中，两个仍提出建议，另一个耗尽预算。变更 API 前还要逐项检查原始表格和推导
动作的失败反馈。

归档评分器实际会排序身份键和期望种子。归档 README 关于“键顺序导致完整映射
失败”的说法得不到该评分器支持。保留归档原样，使用它的实际严格契约比较，
包含原位置和单位；只沿用此前单独说明的强制数量保护比较例外，并另记保护验证。
原来的 0/9 完整映射、0/3 拒答和全部响应继续保留。

原十二个已知任务重新运行属于回归，不算留出结果。记录产品和提示词变化，
不把比较解释为某一个因素的独立因果效果。

## 新自建任务

开发集和留出集分别十二项，均为八项可映射、四项应拒答，使用新的实验标签、
数值、位置及明确的中英文请求。在实现前固定以下配对家族，覆盖全部五种稿件格式。

| 家族 | 必须区分的问题 | 开发稿件／留出稿件 |
| --- | --- | --- |
| 01 | 不同 checkpoint 的等值结果；准确种子身份 | LaTeX／Markdown |
| 02 | TSV 标量损失、过期正文值、精确小数显示 | Markdown／LaTeX |
| 03 | 等价 fraction／percent 字段，原表格单元格 | Word／Word |
| 04 | 含斜线和点的 JSON 键与转义指针，旁置干扰 CSV | Markdown／Quarto |
| 05 | 两个明确实验的百分点差 | Quarto／LaTeX |
| 06 | 原始百分数值与准确 PDF 原位置 | PDF／PDF |
| 07 | 明确 Excel 工作表／区域及字符串实验身份 | Word／Markdown |
| 08 | 明确分子和基线的相对百分比变化 | LaTeX／Quarto |
| 09 | 缺少必需种子，必须拒答 | Quarto／Word |
| 10 | 即使数值相同也缺少 checkpoint 身份，必须拒答 | PDF／LaTeX |
| 11 | 未声明来源单位，不能按数值量级猜测 | Markdown／PDF |
| 12 | 缺少观测与检验元数据，却要求显著性结果 | LaTeX／Quarto |

在产品调优前提交并哈希生成器、请求、原始文件和参考契约。“留出”表示最终产品／
提示词冻结前不打开其推理结果用于调优；任务由开发者自建，不是开发者盲测或
独立真人研究。不能替换失败任务、缩小任务或运行后重标失败。
标注与推理输入分开：提示词可包含请求、来源文档和产品发现／检查输出，不能包含答案。

## 冻结、执行和评分

通过 AgentSession 调用真实本地 Qwen3-8B Q4_K_M，使用已有模型和 llama.cpp 运行时，
重新核对哈希。每次新运行前固定模型参数、运行时／Python／依赖版本、提示词、
动作／错误／token 预算和全部实现／输入哈希。初始沿用最多 16 个动作、3 个无效动作、
每动作 2,048 个完成 token 的预算。旧任务和开发尝试分别记录。打开留出结果前冻结
最终实现与提示词；此后修复只能另记后续运行，首次结果和实现保持原样。

保存每个请求、未修改响应、工具反馈、耗时及 token 用量。本地推理的付费 API
成本为零，不将未测量电力／硬件成本写为零。记录模型进程启动和关闭。
确定性回放与标准答案控制单独列出，不能替代真实推理。分别统计完整身份契约和
原位置、必要拒答、无效动作、未完成会话和保护失败；即使模型仍不适合自主使用，
也必须公布全部结果。
