# 单独许可的原生 Word/PDF 试验 v1

[English](README.md)

本试验用于 PaperDelta 1.1。查看原生排版之前，按完整论文家族划分两个开发样本与
两个留出样本；每篇包含原始出版商 PDF 与 Word 附件，共八个原文件。四篇均来自
PLOS ONE，不代表所有学术出版排版。开发者同时担任标注者，不宣称独立人工验证。

## 协议和结果

[初始协议](protocol-initial.json)固定划分与每文件 16 个目标：表头后的前 12 个结果
数字，再取摘要/结果正文/注释的前四个结果数字；不存在时顺延表格结果并记录回退。
数字行标识、方法常数和日期不属于结果。[运行环境修订](annotation-runtime-amendment.json)
在代码修改和留出查看之前记录：缺少 LibreOffice/pdftotext，因此改用只读 Word 16
导出加 Poppler 渲染，以及独立 PDFium 字形坐标。操作前后核验原文件哈希。

开发集答案在开发之前锁定。[实现锁](implementation-lock.json)在留出查看之前冻结
全部核心代码、包元数据与提取/评分脚本。留出答案依据原始 OOXML、PDFium 坐标和
Word/PDF 页面目视检查标注，[锁定答案](held-out-gold-lock.json)后才有
[首次评分启动](first-run-start.json)。`implementation/` 保存原实现，首次结果不替换。
标注准备中发生的偏移索引错误及修正保留在[记录](annotation/setup-note.json)中；
修正前没有产生任何留出评分。

| 运行 | 目标 | 支持 | 漏检 | 错位 | 未知 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 开发集，1.0 基线 | 64 | 1 | 0 | 0 | 63 |
| 开发集，冻结的 1.1 | 64 | 49 | 0 | 0 | 15 |
| 首次留出，冻结的 1.1 | 64 | 4 | 4 | 0 | 56 |

原始结果：[1.0 基线](baseline/development-v1.0.json)、
[1.1 开发集](results/development-v1.1.json)、[首次留出](results/held-out-first.json)。
基线仅核对匹配的受控证据；1.1 额外要求每个证据值加 1 后在同一原位置产生不一致。
这不是同条件速度对比，也不是复现论文实验。1.1 每次运行保留配置、证据、两份报告
与诊断；`results.csv` 为改动后的证据，原值保留在基线报告。

支持必须满足独立原位置唯一、明确绑定、原证据通过、变化后同位置不一致。未知是
明确的不支持或歧义，不算成功；漏检指没有唯一候选或覆盖该位置的拒绝；错位指
数字或位置错误，即使数值碰巧相同。观察到零错位不构成普遍保证。留出 Word 为
0/32 支持，PDF 为 4/32；多值单元格、不规则表格与歧义身份占多数未知。
PET PDF 四个正文目标因单词和数字被拼接而漏检，不宣称整体高准确率。

自有旋转/裁切/合并/脚注样例及八条双语浏览器流程属于另行回归验证，不增加原生
论文数量或留出成功数。参见 [1.1 功能范围](../../docs/zh-CN/v1.1.md)。

## 重放

在源码根目录解压评测包并安装依赖。原结果记录关键版本：python-docx 1.2.0、
lxml 6.1.3、pdfplumber 0.11.10、pdfminer.six 20260107。

```sh
python -m pip install '.[dev,mcp]'
python tools/replay_native.py --out build/native-replay
python tools/evaluate_native.py --split all --out build/native-current-regression
```

两条命令均要求新目录。第一条复制冻结实现和输入到独立临时树，逐项对比原结果；
第二条检查当前实现并记录是否仍符合原锁。依赖版本另行记录。重复运行这些已见
文档只能称为回归，不能称为新的留出试验。

历史基线脚本在 `baseline/` 保留原字节。重放它需要 commit
`169a3bee0c152ec6a2168426793489547b2bb5b8` 和原依赖；将脚本放到
`build/score_native_dev.py`，协议、开发集答案与 `papers/` 放到 `build/native-v1/`，
不要覆盖历史结果。标注脚本保留原工作路径，仅作为方法记录；重新标注不得覆盖锁定答案。
