# 映射会话：1.4 的真实模型记录

[English](README.md)

这些结果来自真实的本地 Qwen3-8B Q4_K_M 响应，不是脚本编写的模型答案。
十二项合成任务及原始评分器沿用 mapping-v1，原字节不变。开发者拥有并已经看过此套
任务，两轮均不属于新盲测或独立真人研究。推理过程中没有接受任何绑定。

没有测量电费和硬件折旧。协议及服务日志记录硬件、模型/运行时哈希、启动与生命周期
时间，两轮自有模型进程均在结束后停止。PaperDelta 不分发模型权重或推理运行时二进制。

首轮反复将路径或短语用作名称，并遗漏表格约定。纠正版增加名称模式、双语字段说明、
嵌套校验字段路径，以及更易读的建议主键顺序。这些修改受到已观察失败的启发；实现
与提示在第二轮推理前单独冻结，首轮没有被替换。两轮使用相同任务、种子、模型及纠错
预算。与更早 staged-v3 相比还改变了提示、产品和动作/错误预算，不能归因于单一因素。

结构合法提案增加**没有**带来正确的完整映射。第二轮仍混淆来源单位、显示精度和明确
身份约定，且在两个必须拒答的任务中提出映射。一项其余部分较接近的提案也与有序身份
主键约定不同。评分器保持原样，主键顺序、来源身份、单位、显示和原文位置都需要匹配。
补充身份比较只忽略构建器额外要求的数量约束，其余参考字段不放宽。耗尽预算属于失败，
不算拒答。模型说“成功映射”不代表已经通过确定性检查或科学判断。

  不进入提示或纠错反馈。

无需模型即可重放已保存动作：

```sh
python tools/replay_mapping_v4.py --out build/mapping-replay
```

该命令核验两份冻结实现与输入身份，并逐项检查历史状态、错误及最终提案。这是基于
真实历史响应的确定性回归，不是再次模型推理。新的推理运行使用
`python tools/evaluate_mapping_v4.py prepare --directory build/new-mapping-study`
和新目录，配合字面回环地址上的 OpenAI 兼容本地
端点，并保留新协议和所有结果。

PaperDelta 原创代码及任务材料保留仓库 MIT 许可。缓存 Qwen 模型采用 Apache-2.0、
llama.cpp 采用 MIT；既有第三方声明与运行时来源记录提供详情，此处不分发二者。

最终发行版默认展开联合复核的证据表，并在重绘后恢复复选框焦点。这项仅涉及浏览器的
调整发生在第二轮模型冻结之后；文件哈希见[发行调整](../../docs/assets/v1.4/release-adjustments.json)。
