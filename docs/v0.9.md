# PaperDelta 0.9: more experiment evidence

[简体中文](zh-CN/v0.9.md)

Version 0.9 adds TSV, static Excel and normalized experiment exports, with explicit
MLflow and W&B imports. These sources share the existing evidence calculations,
typed identities, Studio batches and author acceptance. Start with the
[complete experiment-evidence guide](experiment-evidence.md).

## Upgrade

```sh
python -m pip install --upgrade 'paperdelta[docx,pdf]'
```

Core LaTeX/CSV/TSV/Excel/local-export projects can use `paperdelta` without extras.
Only the W&B adapter needs `paperdelta[wandb]`. MLflow uses its read-only REST API.
No checking command automatically connects to either platform.

Accepted CSV/JSON configuration and report identities remain unchanged. New source
formats require configuration/report schema 5; older schemas remain readable.
Accepting a new source upgrades the configuration through the usual reviewed
proposal and backup. Compatible 0.6–0.8 Studio drafts can be restored after validation.
Proposals retain exact tool-version guards; regenerate earlier proposals before import.

## Behavior

- Select the original Excel worksheet and range. Inspect actual stored numbers and
  cell positions; reject stale formula caches and unsupported date/merged cells.
- Keep leading-zero text IDs and missing values. A missing grouping identity or
  measurement remains unknown while unrelated valid results remain available.
- Capture explicit platform runs, full metric histories, step/checkpoint/seed/split
  identity, missingness and upstream precision in a new portable export.
- Verify embedded snapshot hashes and rederive normalized rows offline. Show the
  provenance in Studio and bilingual HTML. Do not overwrite previous exports.
- Use TSV/Excel/exports in existing terminal/MCP drafts, templates, individual and
  batch binding. Templates keep source contracts without borrowing manuscript positions.

## Verification

```sh
python -m pip install '.[dev,mcp,wandb]'
python tools/run_tests.py -q
node tools/validate_evidence_browser.cjs build/evidence-check
```

Choose a new output directory. `PAPERDELTA_PYTHON`, `PLAYWRIGHT_MODULE` and
`BROWSER_EXECUTABLE` can identify local runtimes. Six browser flows cover three new
source formats × English/Chinese, exact numbers, source contracts, language changes,
two explicit batch acceptances per project, unchanged inputs, offline reports and
mobile width. See the [browser receipt](assets/v0.9/browser-evidence.json).

Adapter tests use actual local MLflow HTTP requests and the installed W&B SDK's real
scanner/protobuf pagination with controlled transport. They exercise repeated pages,
empty page gaps, sparse metrics, nonfinite values, typed identities, missing groups,
tampered exports, no-overwrite and offline replay. They do not claim live platform
account testing. Existing manuscript, recovery, packaging and platform checks continue
to apply; the [delivery ledger](roadmap.md) records publication only when verified.

The [native example](../examples/evidence-native/README.md) contains owned TSV/XLSX
fixtures and a local import request. No frozen corpus or earlier evaluation bytes
were rewritten for this release. Statistical conventions, real native document
evaluation and Markdown/Quarto remain the approved later releases.
