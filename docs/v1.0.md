# PaperDelta 1.0: declared statistics

[简体中文](zh-CN/v1.0.md)

Version 1.0 checks a mean, SD, SE, n, confidence level and Student-t interval
against one explicit set of observations. It supports whole compound expressions
in LaTeX, Word and PDF, with the same preview and acceptance workflow as scalar
bindings. See the [complete statistical guide](statistics.md) and
[runnable five-seed example](../examples/seed-statistics/README.md).

## What changes

- Declare the complete seed/observation ID set, expected n, variance convention,
  analysis unit and optional interval method, level and sampling assumption.
- Missing/duplicate seeds, absent measurements and nonfinite values become unknown.
  No silently reduced sample size, imputation or automatic significance test.
- Bind mean ± SD, mean ± SE, interval or mean-with-interval as one expression;
  independently bind n or the written confidence level where needed.
- Use the same controls in bilingual Studio, batch templates, terminal guides,
  JSON proposals and read-only MCP. Repair a whole compound by its first number,
  then inspect and accept the complete proposed location.
- Read the declared conventions and numeric results in Studio and offline HTML,
  including when all bindings pass. Word/PDF files remain read-only.

## Compatibility and numerical scope

```sh
python -m pip install --upgrade 'paperdelta[docx,pdf]'
```

The core adds the small pure-Python mpmath dependency for high-precision Student-t
quantiles. It needs no model account, network service or compiled scientific stack.
Exact rational moments precede decimal square roots and interval calculations;
irrational results are explicitly approximations. See the guide for bounds and
supported assumptions. A declared assumption is not proof of independence or normality.

New statistical declarations require configuration/report schema 6. Accepted older
configurations and reports remain readable; optional new fields are omitted from
legacy serialized definitions. Existing scalar identities remain unchanged. A
compatible 0.6–0.9 Studio draft can be restored after validation; tool-version-bound
proposals must be regenerated. A new declaration upgrades the accepted config only
through the normal preview, explicit acceptance and backup.

## Verification

```sh
python -m pip install '.[dev,mcp,wandb]'
python tools/run_tests.py -q
python tools/validate_examples.py --out build/statistics-examples
node tools/validate_statistics_browser.cjs build/statistics-browser
```

Use new output directories. `PAPERDELTA_PYTHON`, `PLAYWRIGHT_MODULE` and
`BROWSER_EXECUTABLE` may identify local runtimes. Browser acceptance covers six
LaTeX/Word/PDF × English/Chinese workflows and two bilingual batch-template flows.
It checks explicit choices, full compound selection, confidence-level binding,
language preservation, template restoration, unchanged inputs and mobile width.
The [eight-flow browser record](assets/v1.0/browser-evidence.json) accompanies
[English](assets/v1.0/statistics.en.png) and [Chinese](assets/v1.0/statistics.zh-CN.png)
screenshots of the actual statistical controls.

Numerical tests use NIST reference values and independent df=1/df=2 closed forms,
large offsets with tiny variance, constant observations, typed IDs, missing seeds
and distinct SD/SE conventions. Native prose and tables retain their own positions;
repairs and later result changes are checked. The public example changes uncertainty
while keeping the mean unchanged, then removes a seed to require an unknown result.
LaTeX compound patch tests rederive replacements, reject stale/tampered input,
preserve BOM/CRLF and unrelated bytes, and restore the exact original file.

The [delivery ledger](roadmap.md) records publication after exact artifact checks.
Frozen evaluation materials and licenses are preserved byte-for-byte. Licensed real
native-document evaluation and Markdown/Quarto remain the next approved releases.
