## Delivered behavior

English and Simplified Chinese cover CLI help, errors, prompts, reports, MCP
presentation, CI summaries, maintained documentation, examples, screenshots and
captioned recordings. One offline HTML file switches languages while preserving
filters, expanded evidence and focus. Machine fields, evidence identities, numeric
decisions and original paper/data text remain stable.

Read-only `doctor` offers actionable diagnostics. UI preferences are isolated from
scientific configuration. Structured command results include write/recovery IDs.
The typed mapping guide supports explicit record identity, units, aggregation,
seeds, multiple locations and final confirmation without nested JSON. Location
repair previews old/new context and preserves scientific definitions. Thirteen
read-only MCP tools share the builder and repair logic; they cannot accept mappings
or write a paper. Stale or ambiguous inputs are refused.

Repository-local Git and package maintainer email use
`101008326+amos689@users.noreply.github.com`. Original licenses and frozen evidence
retain their bytes; historical implementations are separately archived for replay.

## Limits and next steps

The small local model generated no complete valid mapping in either staged run.
[Failed results](staged-model-evaluation.md) remain preserved; automatic model
mapping is not accepted. Deterministic construction and explicit review are the
supported workflow. Dynamic TeX outside declared literal contracts remains unknown.
Consistency does not prove scientific validity or execution. Local process recovery
is tested; power loss and network filesystems are outside measured guarantees.

The matching transfer is `build/mac-transfer-v0.2/paperdelta-0.2.0a1-mac-transfer.zip`.
Follow the [Mac guide](../START_ON_MAC.en.md) to reproduce the recorded Apple Silicon
results. Intel and post-launch user feedback remain separate work. Statistics, watch mode, additional
formats and editor integrations remain later work.
