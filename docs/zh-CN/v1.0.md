# PaperDelta 1.0：显式统计

[English](../v1.0.md)

1.0 针对同一组明确观测检查均值、SD、SE、n、置信水平和 Student-t 区间。LaTeX、Word、PDF
中的复合表达式可整体绑定，沿用标量绑定的预览与接受流程。详见[完整统计指南](statistics.md)
和[可运行的五种子示例](../../examples/seed-statistics/README.zh-CN.md)。

## 新增能力

- 声明完整种子或观测标识、预期 n、方差约定、分析单位，以及可选的区间方法、水平与采样假设。
- 缺种子、重复种子、缺测量值或非有限值产生未知结果，不静默缩小样本、填补缺值或检验显著性。
- 整体绑定均值 ± SD、均值 ± SE、区间或均值加区间；必要时独立绑定 n 与原文置信水平。
- 双语 Studio、批量模板、终端向导、JSON 提案和只读 MCP 共用契约。修复复合位置时选择首个
  数字，再审阅并接受完整的新位置。
- Studio 与离线 HTML 展示声明的统计约定和计算结果，全数通过时也能查看；Word/PDF 保持只读。

## 兼容性与数值范围

```sh
python -m pip install --upgrade 'paperdelta[docx,pdf]'
```

核心新增轻量纯 Python 依赖 mpmath，用于高精度 Student-t 分位数。不需要模型账号、网络服务
或本地编译科学计算库。均值和方差矩先使用精确有理数运算，再进行十进制平方根与区间计算；
无理数结果明确属于近似值。支持范围与假设见指南。声明假设不等于证明独立性或正态性。

统计声明使用配置/报告 schema 6。旧配置和报告继续可读；旧定义序列化时省略新的可选字段，
原有标量身份保持不变。0.6–0.9 的兼容 Studio 草稿可校验后恢复；绑定工具版本的提案需要
重新生成。新声明仅经过正常预览、明确接受与备份后升级配置。

## 验证

```sh
python -m pip install '.[dev,mcp,wandb]'
python tools/run_tests.py -q
python tools/validate_examples.py --out build/statistics-examples
node tools/validate_statistics_browser.cjs build/statistics-browser
```

使用新输出目录。`PAPERDELTA_PYTHON`、`PLAYWRIGHT_MODULE`、`BROWSER_EXECUTABLE` 可指定本地
运行环境。浏览器验收覆盖 LaTeX/Word/PDF × 中英文共六条流程，以及两条双语批量模板流程，
检查明确选择、完整复合表达式、置信水平绑定、语言切换保留、模板恢复、输入不变与手机宽度。
[八条浏览器流程记录](../assets/v1.0/browser-evidence.json)附有实际统计控件的
[英文](../assets/v1.0/statistics.en.png)与[中文](../assets/v1.0/statistics.zh-CN.png)截图。

数值测试使用 NIST 参考值与独立的 df=1/df=2 闭式公式，覆盖大数偏移下的小方差、恒定观测、
带类型标识、缺失种子及 SD/SE 区分。原生正文和表格保留各自位置，并检查修复与后续结果变化。
公开示例先在均值不变时改变不确定性，再删除种子，确认结果变为未知。
LaTeX 复合表达式补丁测试会重新推导替换内容，拒绝过期或篡改输入，保留 BOM、CRLF 与无关
字节，并验证撤销能恢复原文件的完整字节。

[交付记录](roadmap.md)仅在精确发行包检查后记录发布。冻结评测材料和许可证字节不变。
获得许可的真实原生文档评测与 Markdown/Quarto 仍是之后已经批准的版本。
