# 规则、文件约定与限制

[English](../rules.md)

1.0 的统计绑定要求明确声明种子、n、SD 约定和区间方法；复合显示、批量模板与
只读智能体共用契约，详见[统计指南](statistics.md)。

安装可选 `docx` 扩展后，Word 稿件沿用相同审查流程。
参见 [Word 支持与只读边界](word.md)；下方 LaTeX 示例仍然有效。

`paperdelta schema KIND` 提供 configuration、proposal-input、proposal、patch、
binding-draft、repair-proposal、figure-record、review-record、snapshot 和 report
的 JSON schema。未知字段、未支持版本、JSON/YAML 重复键和可执行 YAML 标签均被
拒绝。嵌套证据、诊断、位置和覆盖采用严格的[版本化报告约定](report-format.md)。
接口存在本身不等于发行验收通过。

## 证据

CSV 声明主键列及 string/integer/decimal 类型。重复主键、缺列和无效行会报错。
数值指标必须使用数值列，`where` 的类型必须匹配声明；名为 `001` 的模型不能
静默变成整数 `1`。JSON 使用 JSON Pointer，支持 `~0` 和 `~1` 转义。JSON 的
实验身份目前由所选结构声明，检查器不能从结构自动建立非空结论范围。

`unique` 必须恰好命中一条。`mean`、`sum`、`count` 要求明确选择；`expected_count`
和 `expected_seeds` 可让缺失、重复运行返回未知。对现有记录求平均不能替代种子集
约定。向导及分步构造器要求聚合显式提供 `expected_count`；旧手写配置保留版本 1
的可选数量约定。非有限数值、超出支持范围的数量级和除以零会报错。

指标使用 Decimal 运算。比例、百分数、百分点、标量、计数和比值是不同单位。
显示规则明确小数位、half-up/half-even 舍入和可选百分号。百分点差与相对百分比
变化是不同运算。派生操作受限，配置不能执行 Python 表达式。

## 原文位置

解析器索引支持的 LaTeX，包括项目内字面 `input/include`；排除注释、代码环境、
引用和排版参数。未知宏可能隐藏未支持区域，可声明字面参数数量。条件分支和动态
结构命令保守返回未知。检查器不是 TeX 解释器，不编译论文、不运行脚本。

锚点必须唯一且可验证。数值绑定必须选择一个完整数字及支持的显示格式。精确锚点
的文本改变后需要重新绑定；前后文锚点通常能保留数值修改后的定位。UTF-8 字节范围
保留 BOM、中文及原换行。路径及符号链接目标必须位于项目根目录内。
位置修复要求显式目标和最新输入哈希，保留指标定义、单位、来源、谓词与比较范围。

当前资源上限为 200 个包含文件、40 层包含、每个 LaTeX 文件 4 MiB、配置 1 MiB、
普通输入 32 MiB、每个指标选择 10,000 条记录和 1,000 条审阅记录。它们是资源限制，
不代表每种极限输入都已达到某个性能承诺。

## 比较和审阅

比较是声明过的二元谓词，或明确候选集合及方向的排名，并列规则必须明确。它们
不能证明统计显著性或全局 SOTA；结论范围必须由指标筛选条件建立。

当前一致性、历史变化、来源及作者审阅相互独立。选中证据变化时，显示数字可能
仍舍入为同一个值，但旧审阅会失效。无关 CSV 行和行顺序不改变指标语义身份；
原文件哈希仍会使旧数值补丁失效。

## 图表

声明图表可使用 `schema figure-record` 的来源文件，记录输出哈希、输入哈希、脚本
路径及哈希、时间和方式（`manual` 或 `imported`）。身份匹配只表示自记录以来未变，
不证明脚本实际执行或视觉内容正确。缺失记录返回未知；未登记、缺失或歧义的字面
图引用列入覆盖范围。

检查器使用入口与包含文件目录，以及常见图片扩展名。复杂 `graphicspath`、生成
文件名和绘图宏展开需要未来的显式适配器。

## 写入和恢复

补丁使用前从当前检查重新推导；拒绝变动输入、重叠和错误原始字节。相关结论为
错误或未解析时阻止数值修复，避免一批修改只更新数字而遗留矛盾措辞。应用补丁
不改变映射、快照或审阅记录。

每个文件原子替换，事务日志保存原字节；多文件不是一个整体原子操作。未完成
事务阻止后续 PaperDelta 补丁写入，直到恢复。恢复先核对所有备份与目标，作者后续
编辑会使恢复拒绝。写入使用系统级 PaperDelta 锁并反复核验身份，但第三方编辑器
不受同一锁协议约束。

## 成功退出的含义

退出 0 表示必需的已确认检查与给定证据一致。除非启用 `require_complete_coverage`，
它不涵盖未绑定候选或未支持内容。退出 1 表示不一致；退出 2 表示必要检查不完整
或没有绑定。报告始终包含覆盖范围。任何工作流都不认证证据或科学真理。

文字型 PDF 与 LaTeX/Word/PDF 共享指标流程见 [PDF 指南](pdf.md)。按需安装
`paperdelta[pdf]` 或 `paperdelta[docx,pdf,mcp]`。PDF 保留原页坐标，源稿与导出稿
关系需要明确声明。
