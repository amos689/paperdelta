# PaperDelta 0.5：PDF 与源稿/导出稿审查

[English](../v0.5.md)

0.5 增加可选文字型 PDF 检查、原页高亮，以及多稿件共享明确指标的能力。
显式 `export_of` 关系可以指出源稿已更新、导出 PDF 仍过期的情况。0.4 的 Word
支持和已有 LaTeX 流程继续可用。

```sh
python -m pip install --upgrade 'paperdelta[docx,pdf,mcp]'
paperdelta --lang zh-CN demo --document pdf --out pdf-demo --open
```

只安装需要的扩展即可。核心包仍能在没有 PDF/Word 解析依赖时离线检查 LaTeX。
[PDF 与多稿件指南](pdf.md)说明命令、原生坐标、区域声明及支持的排版。所有新增
命令行、报告界面和维护文档均支持中英文。

## 兼容性与边界

配置和报告 schema 4 承载 PDF 位置、解析身份、关联稿件及导出比较，读取器继续
支持 schema 1–3。已有 LaTeX/Word 配置仅在接受新功能时升级版本。配置变更有
预览、输入检查和备份；工具升级后需重新生成未接受的草稿、提案和数值补丁。
历史恢复事务仍然可恢复。

PDF 解析器变化后需要明确修复绑定；不支持内容和扫描区域保持未知。Word 与 PDF
始终只读，建议会指向文档编辑器或源稿导出流程。OCR、通用版式重建、原生文档
写回、Excel 和统计推断不属于本次发行范围。

原生数值范围验证同时修复了“只选中较长数字的一部分”的边界情况。原页预览
只使用与检查输入哈希一致的字节，并限制页数、图像和高亮数量。预览是否可用
不会改变一致性结论。

## 可复现验收

维护中的原生格式测试包含 **22 种 Word 结构 / 110 个标注位置**，以及
**25 种 PDF 排版 / 125 个标注位置**。PDF 的页码和横向坐标与独立写入的绘制
位置比较，纵向边界框与已知基线比较。覆盖中文、拆分绘制、带符号及科学计数
数字、多栏、规则表格和不同纸张尺寸。另有歧义、部分数字、隐藏/透明文字、
扫描、Form 图形、合并单元格、区域边界、解析器变化、过期提案、修复、批量绑定、
监听、只读 MCP 和源稿/导出稿分歧测试。这些原创样例不代表任意 PDF 的准确率。

发行验收还包括历史兼容与完整测试矩阵：Python 3.11–3.14、Windows/Linux 和
两种 macOS 架构；独立核心/完整环境安装；包审计；中英文桌面/手机宽度离线
浏览器检查；并分别记录冷进程、热进程、纯 HTML 与原页渲染耗时。热检查仍会
重新读取和解析文件，不从本机测量推导跨机器性能承诺。

具体命令、测试数量、平台结果、耗时与文件身份，请查看发行提交对应的成功
Actions 作业及所附验证包。普通 GitHub 发行版和 PyPI 使用同一组已经验证的
wheel/sdist 字节，`SHA256SUMS` 与 `VALIDATION_SHA256SUMS` 对应发行文件和验证包。
`docs/evidence`、`tests/corpus`、`evaluations` 下的历史证据保持原字节及原版本归属。
