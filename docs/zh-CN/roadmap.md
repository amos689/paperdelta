## 每版共同要求

- 确定性证据身份、精确十进制处理和明确确认。
- 本地运行与可选集成，不强制模型、云账号或遥测。
- 完整中英文界面、命令行诊断和维护文档。
- Windows/Linux/Apple Silicon macOS/Intel macOS，Python 3.11–3.14，原生安装、
  对应浏览器流程和正式发布文件的精确校验。
- 验收后发行正式版本，不以招募真人试用为发行门槛。
- 使用用户 GitHub noreply 身份提交，不添加助手署名。
- 冻结的 `docs/evidence/**`、`tests/corpus/**`、`evaluations/**` 和 `LICENSE`
  保留原字节，新增评测材料另行版本化并记录许可。
- 每版完成其完整批准范围，不能因为较小实现通过测试而隐去未完成内容。

完成版本时添加实际提交、检查、测量和发布记录链接。后续版本在逐项验证前均保持待完成。
