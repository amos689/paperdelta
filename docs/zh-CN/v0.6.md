# PaperDelta 0.6：可视化绑定工作台

[English](../v0.6.md)

在研究项目内运行 `paperdelta studio`，即可在本地浏览器中连接实验证据与论文位置。
数据源查看、CSV/JSON 类型化指标、派生指标、原生位置、PDF 原页选择、预览及明确的
子集确认，均复用已有确定性检查引擎。

```sh
python -m pip install --upgrade 'paperdelta[docx,pdf]'
paperdelta --lang zh-CN -C path/to/project studio
```

[工作台指南](studio.md)包含完整步骤、草稿下载、输入变化、键盘操作、限制和故障排查。
只使用 LaTeX 的用户无需可选解析器或 Node.js。界面和文档均支持中英文；
切换语言不会丢失明确的审查选择。

## 兼容性

配置和报告格式继续采用 schema 1–4。已有 LaTeX/Word/PDF 检查、快照、修复、
CLI 和只读 MCP 工具继续可用。本版为数字绑定增加浏览器中的明确确认入口；
MCP 工具仍然不能接受映射。只有所选绑定需要的指标和数据源才会写入，
原配置会被备份。

旧工具版本的草稿/提案需要重新生成。当前 Studio 草稿可下载，并在同版本、输入未变化
时恢复。会话版本拒绝旧标签页的编辑；文件变化使暂存内容和预览失效。
浏览器展示保留 Decimal 和大整数标识的精度。

Studio 是绑定 127.0.0.1 的本地单用户工具，具有随机会话令牌、来源/主机校验、
严格请求契约和请求大小限制。固定界面资源不依赖 CDN 或统计上报。
表单编辑不写论文、不执行科研脚本、不进行 OCR，也不代替科学判断。

## 验收证据

Python 测试覆盖三种格式的会话流程、论文/数据只读哈希、子集依赖、配置备份、
过期输入、强制预览、撤销/恢复、精确小数、路径越界和真实 HTTP 边界/错误处理。
浏览器验收覆盖六条双语接入流程、PDF 高亮、草稿往返、语言切换、报告下载和桌面/
窄屏布局。历史评测数据和许可保留原字节。

发行流程检查 Windows/Linux、两种 macOS 架构上的 Python 3.11–3.14，另加浏览器
任务、隔离安装的 wheel 和包内容审计。实际通过结果和制品标识以发行提交的 Actions
及验证包为准。机器测试不等于真人易用性或任意文档解析准确率测量。
