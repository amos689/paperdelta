# PaperDelta 0.4：Word 稿件检查

[English](../v0.4.md)

0.4 系列为已有证据检查流程增加可选的 Word 读取能力。安装 `paperdelta[docx]` 后，
运行 `paperdelta --lang zh-CN demo --document docx --out word-demo --open`。
[Word 指南](word.md) 说明了受支持结构、原生位置和限制。

拆分在多个 Word 格式片段中的数字会合并读取。检查位置采用段落和表格单元格，
不使用源码行号或字节地址。稳定上下文和明确的表格身份支持绑定、批量选择与修复。
已有检查、比较、快照、范围、监听和只读 MCP 工具适用于 DOCX。HTML 展示段落上下文
和中英文位置标签。不支持的结构仍明确标为未验证。

Word 稿件始终只读。报告提供建议值以及对应段落或单元格；请在文档编辑器中完成修改，
再运行检查。核心 LaTeX 安装及受保护的补丁和恢复流程保持原有行为。

## 升级

```sh
python -m pip install --upgrade 'paperdelta[docx]'
```

使用原生文档的配置和报告需要 schema 3。schema 1/2 的 LaTeX 项目及历史报告仍可读取。
升级工具后，请重新生成尚未接受的草稿、提案和补丁；它们绑定工具版本，以避免接受
过期工作。已有恢复事务仍可恢复。

## 发行检查

维护中的原生测试包含 22 种 Word 正向样例、110 个标注位置，以及负向结构、文件包和
完整工作流测试。它们补充已有的 LaTeX 与历史兼容性测试，不改写冻结评测证据。
测试矩阵覆盖 Windows、Linux 和两种 macOS 架构上的 Python 3.11–3.14。
包验证使用独立的核心和完整环境安装，审计运行时字节，包含内置 DOCX 示例。

发行沿用[已有的工件验证流程](v0.3.md)：构建一次，通过发行提交的检查后发布普通
GitHub 发行版，再通过可信发布将完全相同的 wheel/sdist 字节上传到 PyPI。
发行校验和标识实际公开的文件；历史证据始终对应其自己的版本。

文本 PDF 和多稿件支持属于下一条已批准的 0.5 主线。本版不包含 OCR、Word 写回，
也不推断科学结论正确与否。
