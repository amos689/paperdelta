# PaperDelta 0.8：Studio 批量绑定

[English](../v0.8.md)

Studio 现在可以在结果表中复用明确的实验定义、保存可迁移的实验模板，并将现有 CLI/MCP
提案导入图形界面进行子集复核。LaTeX、Word 和文字型 PDF 共用同一套证据规则。
运行 `paperdelta studio` 开始，完整步骤见[工作台指南](studio.md)。

## 升级与兼容性

```sh
python -m pip install --upgrade 'paperdelta[docx,pdf]'
paperdelta --lang zh-CN -C path/to/project studio
```

仅使用 LaTeX 时可直接安装不带 extra 的 `paperdelta`。已接受配置、报告和快照沿用原有
schema。兼容的 0.6/0.7 草稿经核验后可以恢复；未知或未来草稿版本会拒绝。导入提案仍需
满足原始版本与输入保护。旧版本生成的提案应先用当前版本重新生成，再导入。

## 本版变化

- 根据明确的实验身份对 CSV 分组，筛选目标划分，共用单位、聚合、记录数、种子和显示声明。
- 指标和位置每页 20 项，支持搜索。选择前核对类型化证据、上下文匹配与缺失身份字段；
  相同结果，包括表格中反复出现的相同值，都不会自动形成对应关系。
- 保存实验模板，或下载后导入到兼容的新数据源。模板包含来源契约和设置，不携带论文位置。
- 导入 CLI 或 MCP 产生的数字、结论、图表提案；核对准确定义，只接受选中的子集及必需依赖。
  导入草稿支持恢复，也支持在输入变化后明确选择需要重建的内容。
- 新增控件和诊断全程支持中英文，跨页选择时切换语言仍保留操作内容。

批量绑定目前需要已声明的 CSV 来源。JSON 与派生指标仍使用单项绑定；不同单位或计算方式
需分批处理。缺失或无效证据保持未知，不能从批量目录暂存。模板只填充表单，导入和暂存
不会接受绑定。论文与实验数据保持只读，继续沿用本地运行及明确确认要求。

## 接入操作量实测

同一份确定性稿件与 CSV 包含六种模型身份、四个结果列，每个模型三个测试种子。
24 个均值刻意使用相同长小数，文本编号 `001` 和 `1` 保持区分。流程包括声明数据源、
关联全部 24 个单元格，再逐项确认所有绑定。

| 记录的浏览器操作 | 已发布 0.6.0 | 0.8.0 |
| --- | ---: | ---: |
| 点击、填写、选择和勾选 | 270 | 103 |
| 已确认且检查通过的绑定 | 24 | 24 |

这个机器驱动案例的操作量**减少 61.9%**，不代表真人耗时、错误率或任意论文的表现。
两条流程都复用未变化的表单值，不计无效重复填写、选择和勾选；都计入来源声明和最终逐项
确认，模板及语言切换验收不计入比较。输入 SHA256 完全相同。基线使用已发布的 0.6.0 wheel，
SHA256 为 `f1e33ad34d25cdaf294131e1fc755f70eea0c2e2afda142bf975799eb5b73eee`。
完整[操作轨迹](../assets/v0.8/setup-effort.json)保留两条路径。

## 复现验证

在开发环境安装 `.[dev,mcp]` 和 Playwright 后运行：

```sh
python tools/run_tests.py -q
node tools/validate_batch_browser.cjs build/batch-check --record
```

输出目录必须是新的。可通过 `PAPERDELTA_PYTHON`、`PLAYWRIGHT_MODULE`、
`BROWSER_EXECUTABLE` 指定本机运行时。浏览器套件执行三种格式 × 两种语言的六条流程：
跨页选择 24 个位置、复用并导入模板、接受 12 个绑定，再导入真实 CLI 提案接受六个，
最后导入真实只读 MCP 提案接受剩余六个。检查精确结果、原论文/数据哈希、PDF 原页高亮、
窄屏宽度、网络请求和浏览器错误，原始记录见[浏览器回执](../assets/v0.8/browser-batch.json)。

操作量比较需将核验过的 0.6.0 wheel 安全解包到独立目录，将 `PAPERDELTA_BASELINE_RUNTIME`
指向该目录，再使用新输出目录和 `--effort-only` 参数运行浏览器命令。脚本核对旧版本号、
输入哈希和完整确认结果，并要求操作量至少减少 50%。常规 CI 不下载历史基线，执行当前完整流程。

`--record` 记录真实中英文界面。运行
`python tools/encode_readme_demo.py build/batch-check/recording docs/assets/v0.8`
可编码为动图。五帧、22 秒的播放节奏便于阅读，不表示执行耗时。CI 保留首次接入、日常审查和
规模套件，新增批量流程；发行验证覆盖 Windows/Linux、Apple Silicon/Intel macOS 以及
Python 3.11–3.14 的安装包检查。

这些案例验证交互和身份处理，不用于声称对未见科学文档的抽取准确率。独立真实文档试验仍在
[已批准路线图](roadmap.md)中；冻结证据和许可保持原字节。
