# PaperDelta 1.4：减少接入步骤，明确复核实验

[English](../v1.4.md)

1.4 将首次绑定整理为 **论文与数据 → 定义实验 → 复核与确认** 三阶段。
原始稿件保持只读，已接受配置继续使用现有版本。批量请求新增可选字段，未使用时保留
旧请求身份。单个指标和位置编辑器仍然可用。

## 复核来源约定

在 Studio 检查数据来源后，选择类型和主键建议。每个建议都有依据，带前导零的身份
保持字符串，Excel 单元格实际存储为数字还是文本也会纳入判断。只有完整读取且不超过
10,000 行的表格才能给出唯一性结论。重复身份、缺失值、Excel 混合存储类型和不完整
样本都会明确显示，不会仅因为结果列当前数值唯一就将其作为身份。

选择一个建议主键并明确应用，再暂存来源；建议本身不改变已接受声明。第二阶段的
**建议实验分组**会给出结果字段、分组列、常量身份和重复实验列。请复核这些选择，
单位、归约、记录数量和种子仍需明确约定。

## 并排复核证据和原文位置

生成批次后启用 **并排复核证据与原文位置**。每张卡片显示指标身份、单位、归约、
数量、种子约束及参与计算的证据，旁边是原文上下文。最多同时显示三个最强上下文
候选及其总数，仍可进入完整候选列表检查全部位置。排序不采用数值相等规则，缺失身份
保持可见。没有默认勾选，一个位置也不能在同一批次分配给两个不同指标。

逐个选择位置、说明依据、暂存并预览。**选中我已复核的全部显示绑定**是明确的最终
选择操作，单个复选框和子集接受仍然可用。最终复核声明与接受按钮依然分开，切换
语言保留表单内容与选择。

同一份未修改的 24 指标样例，在 v1.4 首轮测量中需要 54 次有效浏览器操作，包含两次
语言切换；历史 v0.8 为 103 次、v0.6 为 270 次。六条格式/语言流程通过。这衡量的是
编写的浏览器操作量，不是真人完成时间或独立可用性研究，见[完整记录](../assets/v1.4/onboarding.json)。

## 共用定义和经复核的标签

实验定义包含来源约定、分组/筛选、字段、单位、归约、种子、显示和明确的身份标签。
例如，可声明论文中的 `Ours` 对应来源模型 `001`，同时提供实验依据。同一列和论文标签
不能同时指向 `001` 与 `1`，结果字段不能作为身份标签来源。

在 **共用实验定义** 中预览完整定义并确认后，文件按内容指纹保存在
`.paperdelta/experiments/`。后续批次可以配合兼容的来源约定载入它。修改设置会解除
共用引用，直到保存新定义；不会改变此前已接受的绑定。标签只解释上下文建议，原文
字面锚点和明确位置选择仍然必需。

已接受指标保留解析后的约定快照，定义指纹保留在绑定理由和本地
`.paperdelta/binding-reviews/` 记录中，连同选择的绑定、证据哈希以及接受前后的配置
哈希。记录表示已复核的选择，存在记录本身不证明配置写入已完成；审计应用状态时，
应将 `config_after_sha256` 与配置原字节比较。记录与来源数据均不会上传。

## 有次数限制的 Agent 提案流程

安装可选 MCP 扩展后使用 `paperdelta mcp`。新增只读工具包括：

1. `inspect_source_contract`：检查类型、主键和分组建议及其边界。
2. `inspect_experiment_definitions`：检查已保存并复核的共用定义。
3. `start_mapping_session`：取得发现结果、类型化阶段结构和可用动作。
4. `advance_mapping_session`：提供当前版本、动作和扁平参数。
5. `inspect_mapping_session`：检查或导出最后一份有效草稿。

阶段为 `source`、`metric`、`derived`、`locations`，最后 `finish`；`abstain` 用理由结束
会话。每会话最多 16 次动作、三次无效动作，一小时过期，只存在于当前进程。错误保留
最后一份有效草稿，返回字段路径、诊断和纠正建议。输入改变时，会话以过期状态结束。
名称与文件路径分开，来源单位与论文显示约定分开。

`finish` 确定性检查提案，返回未接受提案及检查摘要，之后仍需导入 Studio 或使用正常
命令行检查与接受。MCP 不接受绑定、不保存共用定义，也不写论文。原有无状态和批量
MCP 工具继续可用，批量请求可以引用共用定义和明确身份标签。

[真实模型试验](../../validation/mapping-v4/README.zh-CN.md)保留首轮失败和单独冻结的
修订轮次。结构合法不等于实验身份正确，不宣称已经实现自主映射；确定性回归与模型
成绩分开记录。

## 兼容与验证

0.6–1.3 的兼容草稿可以经复核恢复，解析器身份或输入改变时仍须正常修复或重建。
配置版本仍为 9，存储报告仍为 8。Word/PDF 可选依赖、离线运行和中英文切换继续保留。

正式发行前要求安装包、双语浏览器流程、精确公开产物以及 Windows/Linux/macOS/Python
全部 17 个指定 CI 作业通过，只有核验结束后才写入[交付记录](roadmap.md)。

本地 Windows 安装包验证通过 801 项测试，跳过三项 POSIX 专项；六条接入和两条共用
定义浏览器流程、十三项隔离启动检查通过。实际安装的公开 1.3 版本生成的草稿在 1.4
恢复，绑定和输入/配置字节均保持不变。
