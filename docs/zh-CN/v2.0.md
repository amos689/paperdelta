# 审查 Agent 建议背后的证据

[English](../v2.0.md)

2.0 为直接、分阶段和批量建议提供统一的证据审查表示。CLI JSON 预览与 Studio
展示相同的实验身份声明、来源字节身份及原始论文位置。版本遵循本项目次版本
“逢十进一”的约定：1.9 之后为 2.0。配置 schema 10、报告 schema 9 及既有
22 个 MCP 工具保持兼容。

## 需要一起审查什么

每条绑定建议集中展示以下内容：

| 审查字段 | 能说明什么 |
| --- | --- |
| 来源路径、精确哈希、格式、工作表/区域或 JSON 指针 | 声明读取的是哪一份本地证据 |
| 列类型、主键和筛选条件 | 声明的实验身份，包括 `001` 这样的字符串 ID |
| 预期数量、种子列和种子集合 | 所选记录是否满足已声明的完整性要求 |
| 来源单位、归约和派生依赖 | 所选数值如何产生计算结果 |
| 原始位置、稿件哈希和周边上下文 | 建议指向源码或原生文档中的哪个位置 |
| 显示规则、原值、期望值及诊断 | 在当前声明之下得到的确定性检查结果 |
| 提供的理由 | 仍需审查的自述，不是另行验证过的科学事实 |

结构化 `review` 使用 `review_schema_version: 1`。
`identity_status: requires_author_review` 与
`rationale_status: unverified_assertion` 区分声明和已计算的事实。
两个不同 checkpoint 可以得到相同均值，数值匹配不能证明实验身份正确。
反过来，论文中的旧数字即使检查不一致，也可能正是应当绑定的正确原文位置。

证据样本明确列出 `records_total`、`locations_total` 和 `truncated`。
最终建议通常展示十条记录，草稿审查展示五条；来源路径、筛选条件及原始坐标
仍可查看。Studio 可以展开完整指标证据。保存建议后，也可运行完整 CLI 预览：

```sh
paperdelta --lang zh-CN bind --proposal mapping-proposal.json --format json
```

返回结果的 `preview.metrics` 保留全部所选记录，统一审查表示提供对应路径，
不会把截断样本当成完整选择。请将 Agent 返回的 `proposal_json` 原样保存后再调用 CLI。

## 纠正分阶段声明

`start_mapping_session` 提供当前 schema。后续调用携带返回的会话 ID 与 revision，
只使用返回的 `allowed_actions`。每次响应包含当前阶段指导和已有证据。

成功执行的步骤如果声明了错误来源或单位，可通过 `advance_mapping_session`
传入 `action: "undo"`、空 `arguments` 和明确理由，撤回最后一个成功步骤。
如果后面已经添加位置，必须先撤回位置步骤，才能撤回更早的指标。
既有十六次动作预算内最多允许四次撤回；三次无效动作仍会耗尽错误预算。
无效动作保留上一份有效草稿。

撤回继续保留所有已观察输入的哈希，包括已经从草稿中移除的来源，不能把
变化后的文件变成“未变化”。过期、失效或已终止的会话需要重新开始。
当证据不能证明实验身份、单位、记录完整性或推导依据时，使用 `abstain`
并记录非空理由。耗尽预算属于未完成，不计作正确拒答。

## 在 Studio 中复核

运行 `paperdelta --lang zh-CN studio`，打开绑定审查并导入保存的建议 JSON。
核对实验身份、原文上下文和所选记录，再选择需要接受的绑定并明确确认。
导入不会自动选择或接受绑定。中英文切换保留已选绑定，同时清除确认。
过期的导入不能复用此前的确认或接受动作。

兼容的 1.9 Studio 持久草稿在恢复时重新验证；恢复不会自动接受。
常规检查及全部 MCP 工具对论文保持只读，映射工具不执行论文代码，
也不写入代表作者已审阅的记录。

## 评测范围

[预注册协议](../../validation/mapping-v5/PLAN.zh-CN.md)区分机器验收和真实
Qwen3-8B Q4_K_M 推理。十二个旧任务作为已观察输入的回归。
二十四个新自建任务在产品调优前冻结：开发集和留出推理集各十二项，
每组包含八项映射及四项必须拒答，覆盖中英文和全部五种稿件格式。

新任务是自建合成案例，不是盲测或独立真人研究。原生位置由既有 1.9 解析器
生成，并在原始 Word/PDF 渲染结果上核对。留出的含义是：选定实现与提示词
冻结前，不使用其模型结果调优。[研究记录](../../validation/mapping-v5/README.zh-CN.md)
保留协议、原始输入、原始响应、成本和首次失败。评测通过本身不赋予 Agent
接受绑定的权限。
