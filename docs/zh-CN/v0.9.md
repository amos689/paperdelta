# PaperDelta 0.9：更多实验证据来源

[English](../v0.9.md)

0.9 新增 TSV、静态 Excel、标准化实验导出，以及明确执行的 MLflow/W&B 导入。
新来源复用已有计算、类型身份、Studio 批量绑定和作者接受流程。
详见[完整实验证据指南](experiment-evidence.md)。

## 升级

```sh
python -m pip install --upgrade 'paperdelta[docx,pdf]'
```

LaTeX、CSV、TSV、Excel 和本地导出只需核心 `paperdelta`，无需可选依赖。
只有 W&B 需要 `paperdelta[wandb]`；MLflow 使用只读 REST API。检查命令不会自动联网。

已有 CSV/JSON 配置及报告身份保持兼容。新来源要求配置/报告 schema 5，旧版本仍可
读取。接受新来源时通过原有预览、接受和备份流程升级配置。0.6–0.8 的兼容 Studio
草稿验证后可恢复。提案仍检查确切工具版本，旧版本提案需重新生成后导入。

## 新行为

- 明确选择 Excel 原工作表与范围，查看实际存储数值和单元格位置，拒绝公式缓存及
  不支持的日期、合并单元格。
- 保留前导零文本身份和缺失值；身份或测量缺失的分组保持未知，其他结果仍可用。
- 将选定的平台运行、完整指标历史、step/checkpoint/seed/split、缺失状态和上游
  精度保存为新的可移植导出。
- 离线检查快照哈希并重新推导标准化记录，在 Studio 和双语 HTML 中显示来源，
  不覆盖以前的导出。
- 在终端、MCP 草稿、模板和单项/批量绑定中使用 TSV、Excel、导出；模板保留来源
  声明，不借用其他论文的位置。

## 验证

```sh
python -m pip install '.[dev,mcp,wandb]'
python tools/run_tests.py -q
node tools/validate_evidence_browser.cjs build/evidence-check
```

选择新的输出目录，可用 `PAPERDELTA_PYTHON`、`PLAYWRIGHT_MODULE`、
`BROWSER_EXECUTABLE` 指定本地运行时。六条浏览器流程覆盖三种新来源 × 中英文，
检查精确值、来源声明、语言切换、每个项目两条绑定的明确接受、原文件不变、离线报告
和移动端宽度，见[浏览器记录](../assets/v0.9/browser-evidence.json)。

适配器测试执行真实本地 MLflow HTTP 请求，以及已安装 W&B SDK 的真实扫描器与
protobuf 分页流程，传输由受控响应提供。覆盖重复分页、空页间隙、稀疏记录、
非有限值、类型身份、缺失分组、导出篡改、不覆盖和离线重放，不声称已测试真实平台
账号。原有论文、恢复、打包和平台检查继续适用；[交付台账](roadmap.md)只在验证后
记录发布完成。

[原生证据示例](../../examples/evidence-native/README.zh-CN.md)提供自有 TSV/XLSX
和本地导入声明。本次不修改冻结语料或以前的评估证据；统计规则、真实原生文档评估
和 Markdown/Quarto 仍属于已经批准的后续版本。
