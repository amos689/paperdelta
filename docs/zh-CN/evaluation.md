最终开发组 **75/75**；第一次留出 **51/75**；完整预期合计 **126/150**。两篇含正文
动态定义（如 `\let`），保守解析器阻止整篇检查，不猜渲染内容。源码及失败均保留。
这是支持范围限制，不能通过关闭保护消除；这些构造本来就不在静态 LaTeX 子集中。

只看一致性状态为 **136/150**。完整预期额外十项失败来自位置级错误：数据问题在
指标诊断中已被发现，但该数值位置先因不支持 TeX 而受阻。保留原严格预期，不看完
结果后改评分。

四十个预设无不一致场景中，32 通过、8 未知、0 误报不一致；十个只改数据的不一致
场景中，8 检出、2 未知、0 静默通过。**8/10** 真实文本修复可执行，替换外字节保持
不变，重查及恢复精确；另两项拒绝修改。八份适用的过期补丁全被拒绝。这些小规模
相关样本不能证明总体误报率低于 5%。

每篇只绑定一个结果，整篇覆盖刻意有限。八篇可检查论文分别有 37–555 个数值候选

候选含非结果数字，未绑定比例不是结果召回率。

## 性能

确定性生成负载为 20 个 TeX 文件、500 个不同绑定指标、10,000,047 字节 CSV、
101,611 条记录。每个指标选三条，其余记录身份独立；计时前必须 500 项全通过。

硬件为 Intel Core Ultra 9 275HX、24 个逻辑处理器、约 32 GiB 内存。启用最终报告
约定后的首次进程内核心检查 **1.563 秒**，20 次后续检查经验最近秩 **P95 1.724 秒**。
每次创建新检查器、重新读取输入；排除解释器启动、导入、模型、报告渲染和训练，
没有清空系统文件缓存。高性能笔记本不代表所有普通电脑或 CSV 布局。

优化前首次 22.429 秒、暖运行 24.410 秒。剖析定位到反复全量行筛选；按列索引先
缩小候选，再核验全部原类型谓词，保留行顺序与身份。主键使用精确类型元组相等。
回归测试将索引筛选与穷举比较，覆盖 Decimal 身份、空条件和独立来源。

```sh
python tools/benchmark.py --out build/performance --warm-runs 20 --hardware "describe this machine"
```

证据：[优化前](../evidence/performance-before.json)、
[当时实现](../evidence/performance.json)。最终 a2 在停止模型服务后重测同负载：
20 次暖运行 **P95 1.866 秒**，首次进程内核心 **1.885 秒**，500 项全通过。
[最终记录](../evidence/performance-final.json)标识当时二十个核心文件。早期结果保留；
同样不清系统缓存、不包含模型、启动或报告渲染。

## 映射评测

[独立映射题集](../../evaluations/mapping-v1/README.md)包含十二个原创合成任务、
无答案导出、已保存提案评分和绑定提交字节的审阅模板。九个任务有参考映射，三个
要求拒答；程序有效性、参考约定一致和真人声明分别记录。

[控制证据](../evidence/mapping-controls/evidence.json)使用已知答案验证测量工具：
正控制匹配九个映射、三次拒答；负控制有七项约定差异、三次证据不足仍提案、一个
无效提案和一个保留的正确旧论文映射。五个错误实验身份仍有相同数字且核心通过，
说明数值一致不能单独衡量映射正确性。

控制含 **零次模型运行、零位独立参与者**。候选精度、歧义率和确认耗时未测量。
未列出的等价约定需裁定，参考差异不自动等于科学错误。首次控制草稿的失败及
86 个冻结文件仍保留在历史目录。

之后的[本地 Qwen3-8B Q4_K_M](local-model-evaluation.md)使用十二个独立准备请求，
没有参考答案上下文、重试或修复。十二个 JSON 外壳可解析，十二份提案都未通过
校验，零参考目标匹配、零次必要拒答。原输入输出全部公开保留；锁定题集 README
描述之前只有控制的时点，不重写该历史事实。v0.2 的[分步运行](staged-model-evaluation.md)
也没有有效完整映射。

独立于模型的 [Codex 开发者操作](../evidence/developer-first-use/evidence.json)确认
十个自编绑定，检出八处数据变化不一致，应用八项修改并恢复字节。它支持本地流程
验收，不代表独立用户速度或模型映射精度。
