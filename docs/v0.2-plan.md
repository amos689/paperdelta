## Acceptance contract

The owner accepts local machine testing and Codex developer/first-user assessment before
launch; independent participants are post-launch work. Do not invent human observations.
No untranslated first-party UI keys, placeholder mismatches or missing paired maintained docs.
Locales must produce the same verdicts, evidence identity, numeric patches and recovery bytes.
Code/configuration names and manuscript/data excerpts are not translated. Preserve original
license texts and frozen logs, with bilingual explanations. Model quality is measured separately
from deterministic builder correctness. Publish both failures and abstentions.

Old reports/configurations/snapshots need an explicit compatibility policy. Changing a
language preference must not change a mapping, review, patch or scientific verdict. Old
proposals/patches must never bypass their existing tool-version and hash checks. Keep the
frozen studies intact; add new study identities when evaluating changed implementations.

## Sequence and deferred scope

Foundation/diagnostics → bilingual reporting/documentation → guided binding → binding repair
and staged agent tools → final local acceptance → native Mac verification.
Each increment includes its translated documentation and meaningful risk-based tests.
Statistics extensions, watch mode, extra experiment formats, arbitrary TeX expansion,
Quarto/Markdown and editor extensions remain future candidates, not v0.2 completion gates.
