# 五个明确种子、均值、不确定性与 n

[English](README.md)

在仓库根目录运行 `paperdelta -C examples/seed-statistics check --out build/review`。
这些是项目自有的简短演示结果，不是复现真实研究。

同一组声明的观测支持四处独立定位的显示：均值 ± 样本标准差、n、置信水平和双侧
Student-t 区间。每个种子一行，明确声明 `ddof: 1`、分析单位与采样假设。原文写的是
95%；如果把声明改为 90%，独立绑定的置信水平也会提示不一致。程序只在声明的假设下
核对数值，不能证明实验运行相互独立或服从正态分布。

在副本中，把首条结果从 80 改为 79，末条从 84 改为 85。均值仍为 82，但标准差与区间
发生变化，相应复合显示会变为不一致。删除种子或其数值则产生未知结果，不会静默剔除
观测后改变 n。

显示语法、精度与支持的方法见[统计指南](../../docs/zh-CN/statistics.md)。Word 和 PDF
共用相同计算，保留原生只读位置；Studio 同样可以绑定其中的复合表达式。
