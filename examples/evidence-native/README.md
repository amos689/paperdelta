# TSV, Excel and a portable offline export

[简体中文](README.zh-CN.md)

These owned synthetic fixtures use the repository MIT license. The workbook is
generated by `tools/studio_evidence_fixture.py`; it is not a real scientific sample.
The text model IDs `001` and `1` are distinct. One accepted binding reads TSV and
the other reads `结果 Results!C3` in a static XLSX workbook.

From the repository root after installing PaperDelta:

```sh
paperdelta -C examples/evidence-native check --report build/review
paperdelta -C examples/evidence-native studio
paperdelta -C examples/evidence-native evidence import import.json --out build/experiment.pdevidence.json
paperdelta -C examples/evidence-native evidence inspect build/experiment.pdevidence.json
```

Both bindings pass. The primary value retains the stored text
`0.80000000000000000000000000001` and displays as `80.0%`. Those extra stored digits
demonstrate parser precision, not accuracy Excel would preserve after resaving a
numeric cell. Use a new output path on a second import; existing exports are not
replaced. Add the generated export as a new source in Studio to inspect its snapshot
provenance and declared columns. That action does not replace existing bindings.

Everything here works with the core package and no network. MLflow/W&B requests,
authentication, precision limits and deliberate source updates are described in the
[experiment guide](../../docs/experiment-evidence.md).
